## ✦ عن Linkora

**Linkora** منصة متعددة المستخدمين لإنشاء صفحات شخصية وتجميع الروابط. كل عضو يقدر ينشئ صفحة تعبّر عنه، يعرض فيها صورته ونبذته وروابطه المهمة، ويخصص شكلها وألوانها وحركتها من غير ما يحتاج يبني موقع من الصفر.

بعد التسجيل، يختار العضو اسم مستخدم فريد، ويصمم صفحته من محرر مباشر، ثم ينشرها ويشارك رابطها أو رمز QR. ويقدر يرجع يعدّلها في أي وقت.

**الموقع المباشر:** [linkora-design.vercel.app](https://linkora-design.vercel.app/)

### ملاحظة بخصوص العضويات والدفع

العضويات حاليًا بتتحكم في الشارات وطريقة عرضها، لكن **كل مميزات المحرر متاحة لكل الأعضاء** بغض النظر عن نوع العضوية. الدفع الإلكتروني أو الاشتراكات المدفوعة التلقائية **مش مفعّلة في الإصدار الحالي**.

## 🧭 طريقة الاستخدام

1. **أنشئ حسابك** باستخدام بريدك الإلكتروني.
2. **اختَر اسم مستخدم** يكون جزءًا من رابط صفحتك العامة.
3. **صمّم صفحتك** بإضافة الصورة والوصف والروابط والألوان وطريقة العرض.
4. **راجع المعاينة وانشر** لما تكون راضي عن الشكل.
5. **شارك صفحتك** بالرابط أو QR، وعدّلها وقت ما تحتاج.

شكل رابط الصفحة العامة:

```text
https://linkora-design.vercel.app/p.html?u=YOUR_USERNAME
```

اسم المستخدم فريد على المنصة، ويتكون من حروف إنجليزية صغيرة وأرقام وشرطة فقط، بطول من 3 إلى 28 حرفًا.

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية:** HTML5 وCSS3 وJavaScript عادي باستخدام ES Modules.
- **تسجيل الدخول وقاعدة البيانات:** Supabase Auth وPostgreSQL.
- **حماية البيانات:** Row Level Security (RLS) ودوال قاعدة البيانات.
- **تخزين الصور:** Supabase Storage.
- **عمليات الإدارة:** Supabase Edge Function باسم `linkora-admin`.
- **الاستضافة والنشر:** Vercel متصل بمستودع Git.

المشروع موقع ثابت، ومش محتاج Framework أو Build Pipeline للواجهة الأمامية.

## 🚀 الإعداد والنشر

الخطوات دي لتشغيل نسخة خاصة بك. هتحتاج مشروع Supabase ومستودع Git متصل بـ Vercel.

### 1. إنشاء مشروع Supabase

أنشئ مشروعًا على [Supabase](https://supabase.com/) وافتح **SQL Editor**.

في قاعدة بيانات جديدة، شغّل الملفات بالترتيب التالي:

1. `supabase/schema.sql` — الجداول الأساسية ودوال الصفحات وسياسات RLS وStorage.
2. `supabase/upgrade_admin.sql` — رسائل الإدارة وأدوات التحكم في الحسابات.
3. `supabase/linkora_features_upgrade.sql` — العضويات وصور الغلاف وإحصاءات الصفحة.
4. `supabase/linkora_display_controls_upgrade.sql` — التحكم المستقل في ظهور الشارات وطريقة عرض الروابط. لازم يتنفّذ بعد ترقية المميزات.

شغّل كل ملف بالكامل وتأكد إنه انتهى من غير أخطاء قبل الانتقال للي بعده. لو بتحدّث نسخة مستخدمة بالفعل، خُد نسخة احتياطية الأول وشغّل الترقيات الناقصة فقط. ما تعيدش تشغيل Schema قديم على قاعدة إنتاج من غير مراجعة.

### 2. إعداد الواجهة

افتح `assets/js/config.js` وحط رابط مشروعك ومفتاح Supabase العام **Publishable key** (أو مفتاح `anon` القديم للمشروعات الأقدم):

```js
window.LINKORA_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT.supabase.co",
  supabaseKey: "YOUR_SUPABASE_PUBLISHABLE_KEY",
  projectName: "Linkora"
};
```

المفتاح العام مخصص للاستخدام في المتصفح، لكن لازم يكون معاه سياسات RLS صحيحة. **ممنوع تحط Secret Key أو `service_role` في الملف ده أو أي ملف Frontend أو مستودع عام.** راجع [دليل تأمين البيانات في Supabase](https://supabase.com/docs/guides/database/secure-data) و[دليل مفاتيح API](https://supabase.com/docs/guides/getting-started/api-keys).

### 3. إعداد روابط تسجيل الدخول

من Supabase افتح **Authentication → URL Configuration**، واضبط Site URL على رابط موقعك، مثل:

```text
https://linkora-design.vercel.app
```

وأضف روابط التحويل التالية (مع استبدال الدومين لو بتستخدم دومين مختلف):

```text
https://linkora-design.vercel.app/auth.html
https://linkora-design.vercel.app/auth.html?mode=confirm
https://linkora-design.vercel.app/auth.html?mode=reset
```

أضف روابط التشغيل المحلي لو بتختبر على جهازك، وتأكد إن قوالب تأكيد البريد واستعادة كلمة المرور بترجع المستخدم لنفس الدومين.

### 4. نشر Edge Function الخاصة بالمدير

لوحة المدير بتستخدم Supabase Edge Function باسم `linkora-admin` لتنفيذ العمليات المحمية زي تعديل العضويات، حظر الحساب، إعادة الصفحة، والحذف النهائي.

من مجلد المشروع شغّل أوامر Supabase CLI:

```bash
npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase functions deploy linkora-admin
```

الدالة محتاجة رابط مشروع Supabase ومفتاح عميل عام، بالإضافة إلى مفتاح Secret أو Service Role محفوظ في بيئة تشغيل الدالة فقط. ما تحطش المفتاح السري في ملفات الموقع أو GitHub. الدالة بتتحقق من جلسة المستخدم وبتراجع وجوده في جدول `platform_admins` قبل أي إجراء إداري. احتفظ بإعداد `supabase/config.toml` متوافقًا مع الكود الحالي.

### 5. تعيين أول مدير للمنصة

أنشئ حساب المدير من الموقع أولًا، وبعد وجود الحساب نفّذ الاستعلام التالي داخل Supabase، مع تغيير البريد:

```sql
insert into public.platform_admins (user_id)
select id
from auth.users
where lower(email) = lower('YOUR-ADMIN-EMAIL@example.com')
on conflict (user_id) do nothing;
```

سجّل الخروج ثم الدخول مرة أخرى، وبعدها افتح `dashboard.html`. ما تضيفش صلاحيات مدير إلا لحسابات موثوقة، ومن خلال إجراءات SQL آمنة فقط.

### 6. النشر على Vercel

1. ارفع ملفات المشروع إلى مستودع Git على GitHub.
2. افتح [Vercel](https://vercel.com/) واختَر **Add New → Project** ثم استورد المستودع.
3. اختَر جذر المشروع كـ Root Directory، و**Other** كـ Framework Preset.
4. المشروع Static Site، لذلك مش محتاج Build Command أو Install Command. لو Vercel طلب Output Directory استخدم جذر المشروع (`.`).
5. اعمل Deploy، وتأكد إن الصفحة الرئيسية وروابط المصادقة بتستخدم الدومين النهائي.

بعد ربط المستودع، التحديثات على فرع الإنتاج ممكن تنشر تلقائيًا. راجع [دليل النشر من Git في Vercel](https://vercel.com/docs/git).

### 7. اختبارات قبل الإطلاق

اختبر باستخدام حساب عضو عادي وحساب مدير منفصل:

- التسجيل وتأكيد البريد وتسجيل الدخول والخروج واستعادة كلمة المرور.
- إنشاء بروفايل واختيار اسم مستخدم فريد وإضافة روابط وصورة.
- حفظ الصفحة كمسودة ثم نشرها وفتحها من نافذة خاصة.
- التأكد إن البيانات الإضافية مخفية ما لم يتم تفعيل خيار ظهورها.
- تجربة الزيارات ونقرات الروابط وQR ونسخ الرابط.
- إرسال طلب دعم والرد عليه من لوحة المدير.
- التأكد إن العضو العادي لا يستطيع تنفيذ إجراءات المدير أو منح نفسه شارات.

## 🔐 الخصوصية والأمان

- سياسات Supabase RLS هي طبقة الصلاحيات الحقيقية؛ إخفاء زر من الواجهة مش وسيلة حماية.
- جدول `platform_admins` لازم يفضل محميًا. منح صلاحية المدير يتم يدويًا من مالك المشروع فقط.
- ممنوع نشر Secret أو Service Role Key داخل كود المتصفح أو GitHub. استخدمه داخل بيئة Edge Function المحمية فقط.
- بيانات الصفحة العامة بتطلع عبر دالة مخصصة. الحقول الاختيارية بتظهر حسب إعدادات صاحب الصفحة، وتاريخ الميلاد الدقيق لا يظهر للزوار؛ يظهر العمر فقط عند السماح بذلك.
- صور البروفايل والغلاف محفوظة في Bucket عام القراءة حتى تظهر في الصفحات المنشورة. ارفع فقط الصور التي تقبل ظهورها للعامة.
- اختبر الصلاحيات بحساب زائر وعضو عادي ومدير قبل الإطلاق، وراجع سياسة الخصوصية وشروط الاستخدام والنسخ الاحتياطي وحذف الحسابات.

## 🧪 التشغيل المحلي

المشروع بيستخدم JavaScript Modules، لذلك شغّله من خلال Local Web Server بدل فتح ملفات HTML مباشرة باستخدام `file://`. تقدر تستخدم إضافة Live Server في VS Code أو أي خادم ملفات محلي. أضف روابط التشغيل المحلي إلى Supabase Redirect URLs قبل تجربة تأكيد البريد أو استعادة كلمة المرور.

## 📌 نطاق الإصدار الحالي

Linkora تطبيق ويب متعدد المستخدمين، لكن تشغيله يعتمد على ضبط Supabase وتنفيذ ترقيات قاعدة البيانات المطلوبة. العضويات والشارات بيتم تعيينها من المدير، ومفيش حاليًا بوابة دفع أو اشتراكات مدفوعة تلقائية. الإحصاءات بتحتاج تنفيذ ملف ترقية المميزات المذكور فوق.
